## 6.1. Module Summary

Throughout this module, we have progressively constructed a complete machine translation workflow based on the **MTUOC ecosystem**.

We began by introducing **MTUOC-server** and its role as an interface between translation technologies and external applications. We then deployed and tested open **Neural Machine Translation (NMT)** models, including OpusMT and NLLB.

Once the translation models were operational, we connected MTUOC-server to **CAT tools**, allowing machine translation to become part of a professional translation environment.

The final sections introduced **Large Language Models (LLMs)**. We examined how LLM-based translation differs from conventional NMT, particularly through the use of prompts, contextual information, terminology, examples, and output constraints. Finally, we deployed LLMs through MTUOC-server using two different approaches: **SalamandraTA through Hugging Face** and **Gemma through Ollama**.

The general workflow developed throughout the module can be represented as:

```text
translation model
       ↓
MTUOC-server
       ↓
CAT tool
       ↓
translator
```

The underlying translation technology may change, but MTUOC-server provides a common interface through which different systems can be incorporated into the translation workflow.

## Key Takeaways

After completing Module 1, you should remember that:

* **MTUOC-server provides a common interface** between different translation technologies and client applications.
* Open **NMT models** can be selected, tested independently, configured, and deployed through MTUOC-server.
* MTUOC-server can be connected to **CAT tools**, making locally deployed MT systems available within professional translation workflows.
* **LLMs introduce prompting as an additional component** of the translation system, allowing context, terminology, examples, and other instructions to guide translation.
* Open LLMs can be integrated into MTUOC-server using different deployment frameworks, including **Hugging Face and Ollama**.
* Regardless of the underlying technology, the general principle remains the same:

```text
translation technology → MTUOC-server → CAT tool → translator
```
