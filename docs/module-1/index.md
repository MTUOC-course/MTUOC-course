# Module 1. Deployment, Integration and Evaluation

Welcome to Module 1 of the course. This module covers the deployment of machine translation engines, their integration into professional CAT tools, and the evaluation of NMT models and Large Language Models (LLMs).


* **[1. The MTUOC project](1.-The-MTUOC-project)**
  * Core ecosystem, server architecture, installation, and basic usage.

* **[2. Open Neural Machine Translation models](2.-Open-Neural-Machine-Translation-models)**
  * Deployment and usage of open-source NMT architectures such as OpusMT and NLLB.

* **[3. Integration into CAT tools](3.-Integration-into-CAT-tools)**
  * Connecting MTUOC server with professional translation software including OmegaT and Trados.

* **[4. Large Language Models and translation](4.-Large-Language-Models-and-translation)**
  * Overview and application of LLMs within machine translation workflows.

* **[5. Large Language models integration into MTUOC server](5.-Large-Language-models-integration-into-MTUOC-server)**
  * Practical integration of open LLMs (such as SalamandraTA and Gemma) into local pipelines.

* **[6. Summary and Self-Assessment](6.-Summary-and-Self-Assessment)**
  * Global review of Module 1 concepts and self-assessment evaluation.
